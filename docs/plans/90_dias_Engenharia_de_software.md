# Plano de Desenvolvimento — 90 Dias de Engenharia de Software

Plano mestre de estudos e práticas em Engenharia de Software, Harness Engineering, Domain-Driven Design (DDD) e Specification-Driven Development (SDD).

---

## Semana 1 — Fundamentos de Harness Engineering & SDD

### Objetivos da Semana
- Compreender o conceito e propósito de **Harness Engineering** e testes automatizados como harness.
- Entender a aplicação de **Specification-Driven Development (SDD)**: orientar o desenvolvimento por especificações testáveis antes da escrita do código.
- Configurar o ecossistema de estudo e repositório local com práticas rastreáveis via issues e registros de aprendizado.

### Tópicos Chave
1. **Harness Engineering**: O que é, por que é crítico para evolução de software confiável e como criar harnesses de testes.
2. **Specification-Driven Development (SDD)**: Escrever especificações claras com critérios de aceitação verificáveis.
3. **Fluxo de Desenvolvimento Incremental**: `Material -> Spec/Proposta -> Issue -> Código + Testes -> Learning Log`.
