# Professional Development

Repositório de execução e evidências práticas para os estudos de Harness Engineering e Engenharia de Software.

## Limites do sistema

- **Drive:** autoridade dos planos de 90 dias e da Base Central.
- **Notion:** registro diário leve.
- **GitHub:** issues, código, projetos, decisões e evidências técnicas.

Não registre aqui casos de Cartório, dados identificáveis, documentos internos, credenciais ou materiais com acesso restrito.

## Fluxo semanal

1. Leia o objetivo da semana no Drive.
2. Abra uma issue para uma prática concreta.
3. Trabalhe em uma branch e registre evidências no projeto.
4. Faça auto-revisão, feche a issue e registre somente evidências reais na Base Central.

## Estrutura

- `docs/`: registros técnicos, decisões, specs e resumos de execução.
- `projects/`: práticas executáveis e artefatos demonstráveis.
- `templates/`: modelos reutilizáveis.
- `.github/`: entrada padronizada de práticas via issues.
