# Como praticar neste repositório

Use o fluxo `issue → branch → prática → evidência → auto-revisão → fechamento`.

1. Abra uma issue com objetivo, escopo, critério de aceitação e evidência esperada.
2. Crie uma branch curta e implemente apenas o escopo definido.
3. Rode a validação descrita no README do projeto.
4. Registre o resultado real, inclusive bloqueios ou trabalho parcial.
5. Feche a issue somente quando a evidência e o critério de conclusão existirem.

Não envie credenciais, dados pessoais, conteúdo interno ou qualquer dado de Cartório.
