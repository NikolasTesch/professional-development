# JavaScript — Semana 1

Prática autoral de funções, validação de dados, arrays e módulos ES.

## Como executar

```bash
npm start
```

## Como validar

```bash
npm test
```

O módulo `summarizeGoals` resume uma lista de minutos de estudo. Ele cobre entradas normais, lista vazia e valor inválido.

## Decisões

- `reduce` calcula o total, pois o objetivo é transformar uma lista em um único valor.
- A validação rejeita valores negativos e itens que não são números.

## Limitações

Este é um exercício pequeno; não persiste dados e não oferece interface.

## Evidência

O teste automatizado e o histórico de commits são a evidência inicial desta prática.
